# Todo

Work that is not done yet. Each note says what is wrong and what done looks like.

When a task is finished, move its note into `changes/done/`. Opening a todo alone does not need a revision-log section. When the finished work changes how the suite runs or is configured, append a section to `changes/ai-revision-log.md` even if no Cursor rule already named the old decision. The section names `git config --global user.name`, the UTC time, and the commit the change was made on top of. It says what changed, concretely enough to unpick.
